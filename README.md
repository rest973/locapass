# LocaPass · 0-A 프로토타입

지역 패스로 짜인 여행 제안 서비스 LocaPass(로카패스)의 프로토타입입니다. 화면은 다섯입니다 — 여행 피드 · 여행 한 페이지 · 지역 · 출발 도시에서 · 보관함(`index.html`, 해시 라우팅). 콘텐츠 단위는 여행(`data/trips.json`, `cards.json`에서 `build_trips.py`로 생성)이고 패스는 그 부품입니다. 실험용이며 정식 서비스가 아닙니다.

- 계정·서버 없음. 보관한 여행은 주소창(#/saved?ids=)과 브라우저에만 저장됩니다.
