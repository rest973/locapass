# LocaPass 데이터

- `passes.json` : 패스 단위 사실. 기획서 §7 스키마. `trust_level` L1(추출만)·L2(교차 확인)·L3(사람이 원문 대조). `card_status: no_card`는 데이터에만 있고 카드로는 만들지 않은 패스(채택 기준 미달)와 그 이유.
- `cards.json` : 화면에 나오는 "여행 한 장". 패스 하나가 여러 장이 될 수 있다(`pass_id` 참조). `front`는 앞면 세 줄, `back`은 뒷면 블록, `photo`는 사진과 출처.
- 라이선스: 데이터는 ODbL 1.0. 카드 문장은 CC BY-SA 4.0. 사진은 각 항목의 라이선스를 따른다.
- 가격·조건은 확인일 기준이다. 구매 전 창구에서 최종 확인.
